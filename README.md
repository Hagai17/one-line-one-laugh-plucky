Entry for the make.fun bounty [One Line, One Laugh](https://make.fun/b/u-plucky-finch-20-one-line-one-laugh-0ffe66ea?utm_source=github&utm_medium=readme&utm_campaign=one-line-one-laugh-plucky).

`main.py` writes the line to `/output/entry.txt`:

> Grandpa's hearing aid whistles every time Grandma talks. Sixty years of marriage, and the man owns a mute button with plausible deniability.

The line was picked by duelling seventeen drafts against the competition's
published judge brief, then iterating the internal champion against the
strongest lines in the live field (sampled first-hand via the submissions
API). The full draft list and duel record are in
[candidates.md](candidates.md).

## Run

```sh
python3 main.py   # writes /output/entry.txt and prints the line
```
